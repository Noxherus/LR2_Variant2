# Лабораторная работа № 2. Вариант № 2

**Тема:** Векторы. Итераторы.  
**Цель:** научиться работать с одномерными массивами и векторами в C++.

## Задание 1

Создать целочисленный вектор, отсортировать его по убыванию и заменить элементы с чётными индексами (0, 2, 4, ...) на их порядковые номера (1, 3, 5, ...). Вывести полученный вектор.

**Код:** `Zadanie_1/main.cpp`.

## Задание 2

Написать функцию `part`, возвращающую первую половину и среднюю треть вектора. Найти среднее арифметическое каждой части и количество пар элементов, сумма которых больше максимального элемента исходного вектора, кратного 17.

**Код:** `Zadanie_2/main.cpp`.

## Выполнение

Обе программы написаны на C++ и проверены в консольном режиме. Данные вводятся с клавиатуры, результаты выводятся на экран. Для частей с нечётной длиной используется целая часть при делении, средняя треть выбирается по центру. Пара означает два элемента в разных позициях. Если элементов, кратных 17, нет, программа сообщает об этом.
